<h1>bikumeter</h1>
<h3>A script that brings in activities from Strava, filters them and sends the ones that correspond to commutes to a spreadsheet where I calculate said amortization and other things. I scrape a public transport webpage to get the fare for the ride. It's intentional that it doesn't only get the commute rides but also other rides, which also helped save money on public transport.</h3>

<p>Stack</p>
<ol>
<li>Python</li>
<li>Google Spreadsheets</li>
<li>Strava API/Webhooks</li>
<li>Playwright</li>
</ol>
